# Ryde — Gabès Taxi MVP

A full-stack ride-hailing web MVP for Gabès/Tunisia.

## Included
- Rider booking flow
- Driver online/offline + GPS sharing
- Real-time driver locations with Socket.IO
- Real-time ride events
- Driver ride acceptance
- Ride status updates and cancellation
- Admin dashboard
- SQLite persistence
- Responsive mobile/desktop UI
- OpenStreetMap/Leaflet map

## Run locally
```bash
npm install
npm start
```
Open http://localhost:3000
